# WordBook Edge 插件

这是 WordBook 的 Manifest V3 Edge 扩展。它会读取用户主动选中的文本，并通过服务器的受令牌保护接口保存生词。

## 安装

1. 打开 Edge，在地址栏输入 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目的 `edge-extension` 文件夹。
5. 安装后会自动打开设置页。
6. 填写 WordBook 网页地址，例如 `http://服务器IP:16040`。
7. 填写服务器 `/etc/WordBook.env` 中 `EXTENSION_API_TOKEN=` 后面的令牌。
8. 点击“测试连接”，看到连接成功后即可使用。

如果阅读的是电脑本地 PDF，请在扩展详情页打开“允许访问文件 URL”。

## 使用

- 首选：选中单词后按反引号键 `` ` ``。
- 备用：选中单词后按 `Alt+W`。
- Edge 内置 PDF 阅读器没有响应时：右键选中的单词，选择“添加到 WordBook”。
- 也可以点击工具栏中的插件图标，再点击“添加当前选中的单词”。

录入窗口支持填写释义、例句、PDF 名称、页码、标签和备注。按 `Ctrl+Enter` 可以保存，按 `Esc` 可以关闭。

## 为什么需要右键备用方式

Edge 的新旧 PDF 阅读器可能使用受保护的浏览器内部页面，普通内容脚本不一定能读取其文本层或键盘事件。右键菜单由浏览器直接提供选中的文本，因此在这种情况下更可靠。

另外，Edge/Chromium 的扩展命令要求快捷键包含 `Ctrl` 或 `Alt`，所以单独的反引号只能由内容脚本监听；`Alt+W` 是浏览器级备用快捷键。

## 隐私与权限

- 插件只在用户主动触发时读取当前选中的文本。
- 服务器地址和令牌保存在当前 Edge 配置的本地扩展存储中，不会写入仓库。
- 只有用户配置的 WordBook 服务器会在设置时获得网络访问权限。
- 插件不包含远程 JavaScript，也不会把数据发送到第三方服务。
